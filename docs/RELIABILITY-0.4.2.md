# 0.4.2 전송·응답 지연·투명도

0.4.2 정식판에 포함된 전송·투명도·진단 변경을 설명합니다. **타블렛 환경의 전체 창 멈춤은 실제 장비에서 해결 확인 전입니다.**

## 세 현상을 구분합니다

### 연속 점·쉼표 전송 거절
설치된 게임의 채팅 코드와 필터 코드를 읽어 확인했습니다. 게임은 ChatLanguageFilter가 켜져 있으면 BWFManager.Contains로 검사하며, 여기에는 욕설 외에 문장부호 검사도 포함됩니다. PunctuationManager의 기본 허용 값은 3이고, PunctuationFilter는 ? ! , . ; : - 문자가 이 값보다 많이 연속되는지 검사합니다. 따라서 기본값에서 .... 또는 ,,,, 같은 4개 연속 문장부호가 전송 단계에서 거절되는 동작이 설명됩니다. 혼합 문장부호도 해당할 수 있습니다.

게임은 필터로 방 전송을 막아도 본인 고양이의 말풍선을 띄웁니다. 말풍선이 보이는 것만으로 다른 방 참가자에게 전달됐다고 볼 수 없습니다. 봉고챗에는 방에서 수신한 대화가 표시됩니다. 봉고챗 자체에 ‘문장부호 3개 제한’이나 ‘6개 메시지 제한’을 추가한 것은 아닙니다.

이번 앱은 게임 필터를 우회하거나 자동으로 끄지 않습니다. 실패 안내를 방 전송과 본인 말풍선의 차이를 설명하도록 바꿨습니다. 게임 필터 설정을 바꾸면 적용 결과가 달라질 수 있습니다.

### 입력창 잠금
기존 앱에서 다른 요청 ID의 응답 파일이 존재하면 제한 시간이 지나도 전송 대기가 풀리지 않는 경우를 격리 환경에서 재현했습니다. 잘못된 응답·손상된 JSON·잠긴 파일·너무 큰 응답도 제한 시간 뒤 대기를 해제하도록 수정했습니다. 이것은 확인된 앱 버그이지만, 타블렛 사용자의 전체 창 멈춤과 같은 원인이라고 입증된 것은 아닙니다.

### 타블렛 환경의 전체 창 멈춤
게임 상태/기록/응답 읽기와 전송 파일 쓰기를 화면 스레드 밖으로 옮겼습니다. 전송 대기 중 입력창을 읽기 전용으로 바꾸지 않아 한글 입력기 상태를 유지하고, 답을 기다리는 동안 다음 문장을 작성할 수 있습니다. 같은 대화가 유지될 때는 기존 말풍선을 재사용해 매번 전체 화면을 다시 만들지 않도록 했습니다.

별도 감시 타이머가 화면 스레드의 응답 지연을 기록합니다. 이 처리는 자동 강제 종료나 자동 재전송을 하지 않습니다. 실제 휴이온 장비에서의 증상 해소·정확한 네이티브 멈춤 지점은 아직 확인하지 못했습니다.

## 실제 투명도
기존의 불투명 창에서 Opacity만 바꾸는 대신, Windows가 픽셀 단위 알파로 합성하는 WPF 투명 창을 사용합니다. 이를 위해 창 상단에 버전·이동 영역과 최소화/최대화/닫기 버튼을 제공합니다. 오른쪽 아래로 크기를 조절할 수 있습니다. 뒤 창이 비쳐야 정상입니다. 100%로 올리면 원래의 불투명한 화면으로 돌아옵니다.

## 문제 PC에서 확인할 순서
1. 기존 봉고챗을 완전히 닫고 0.4.2 EXE를 실행합니다. 멈춘 앱은 작업 관리자에서 BongoCatChatMerger.exe만 종료합니다.
2. 창 상단에 0.4.2이 보이는지 확인합니다. 연결 플러그인은 검증된 0.2.2 그대로라 새로 설치하지 않아도 됩니다.
3. 평소 그림 앱에서 타블렛을 사용하면서 일반 짧은 문장을 6회 이상 보내 봅니다.
4. 별도로 .... / ,,,, 등의 필터 안내와 투명도 조절을 확인합니다. 게임 필터 거절은 전체 창 멈춤과 구분합니다.
5. 다시 전체 창이 멈추면 최소 10초 기다렸다가 종료하고 새 EXE를 재실행합니다. ‘연결 도우미’ 우클릭 → ‘진단 내용 복사’로 내용을 확인할 수 있습니다.

응답 지연 파일은 앱의 사용자 폴더인 %LOCALAPPDATA%\BongoCatChatMerger\ui-health.log에 생성됩니다. 시각·버전·처리 단계·환경 정보만 기록하며 채팅 본문은 넣지 않습니다. 자동 업로드·업데이트 서버·메모리 덤프 수집은 없습니다. 기록이 없으면 지연 기준에 도달하지 않은 경우나 다른 형태의 종료일 수 있습니다.

## 검증
기존 120개 + 신뢰성 28개 = 148개 검사이며, 업데이트 확인 31개를 더해 정식판 전체 검사는 179개입니다. 전송 반복은 모의 게임 응답을 이용한 검사이며, 실제 휴이온 PC에서의 반복 전송 성공으로 간주하지 않습니다. 실제 UI 알파 픽셀, 네이티브 투명 창, 창 조작, 비동기 파일 응답, 잘못된 응답 복구, 채팅 본문 없는 지연 로그를 검사했습니다. Windows 11 빌드 26300에서 수행했으며 Windows 10 실기 검증은 아직 하지 않았습니다.
