## 말풍선 고정 오류 수정

실제 게임 로그의 `Invalid header data!!!`, `SelectedLocale is null`, `Vfx.CatSpeech.DoShowSpeech` 예외를 확인했습니다. 게임 원본의 `String.GetHashCode`는 legacy 해시를 사용하지만 추가 Mono 라이브러리는 randomized 해시를 사용하여 Addressables의 catalog marker가 달라졌습니다. 야옹 문구가 null이 되고 말풍선 종료 코루틴이 중단된 원인입니다.

플러그인 시작 시 Addressables의 `kMagic`만 원본 게임의 legacy 값으로 복원합니다. 게임 원본 DLL·데이터 파일 및 전체 문자열 해시 동작은 변경하지 않습니다. 원본 catalog.bin의 marker와 버전을 먼저 검증하며, 지원되지 않는 형식은 거부합니다.

- 원본 catalog.bin의 marker와 legacy 해시 계산 결과 일치 확인
- 잘못된 버전·잘린 파일을 거부하고 marker를 변경하지 않음 확인
- 수정본 실행 로그에서 catalog compatibility ready, 빈 error 및 최신 heartbeat 확인
- 새 실행 로그에서 기존 catalog·localization·CatSpeech 예외가 발생하지 않음 확인
- 사용자가 봉고챗 실행 상태에서 캐릭터 클릭, 말풍선 자동 종료, 이후 채팅 입력·전송 정상 동작 확인

첫 전송 때 창이 사라졌다 나타난다는 보고는 항상 위를 켜면 발생하지 않는 것으로 사용자가 확인했습니다. 게임 창에 가려지는 상황을 피하도록 항상 위를 기본으로 켜고 선택을 파일에 저장합니다. 끈 상태를 새 창에서 복원하는 검사도 통과했습니다.

## 0.2.2 재실행 연결 수정·재연결

Doorstop 4.5.0은 `DOORSTOP_DISABLE`과 `DOORSTOP_INITIALIZED`를 모두 설정합니다. 기존 코드는 INITIALIZED만 제거해 Steam으로 DISABLE이 상속될 수 있었습니다. 두 값이 설정된 자식 프로세스 검사에서 구버전의 실패를 재현했고, 수정본은 두 값을 제거해 자식에게 넘기지 않았습니다. 현재 게임에 포함된 Unity Mono를 별도 검사 프로세스에 호스팅하여 Windows 네이티브 환경에서도 두 값이 사라지는 것을 확인했습니다. 실제 게임 프로세스에 검사 호스트를 주입하지 않았습니다.

- 앱·플러그인 빌드 통과
- 기존 전송·테마·표시 설정 21개 검사 통과
- 재연결 12개 검사 통과: 정상 상태 즉시 복구, 초안·기록 보존, 중복 클릭 방지, 오래된 상태의 성공 오판 방지, 제한 시간 안내, 새 게임 세션 감지, 전송 중 요청 취소·재전송 금지, 방 진입 대기, 미리보기 비활성화
- 오프스크린 화면에서 재연결 버튼 배치 확인

실제 게임의 Steam 종료 → 게임 직접 실행 → Steam 재실행 경로 확인은 별도로 기록합니다.
2026-10-15 실제 설치본 0.2.2에서 사용자가 Steam 완전 종료 → BongoCat.exe 직접 실행 → Steam 자동 시작·게임 재실행 → 방 입장 → 봉고챗 재연결 정상 동작을 확인했습니다. 이전 게임 로그의 RestartAppIfNecessary와 재실행된 게임 로그의 0.2.2 로드, 최신 ready=true·canSend=true·빈 error를 함께 대조했습니다.

## 0.4.2-rc1 전송 복구·투명도·응답 지연 진단
기존 120개와 새 신뢰성 28개로 총 148개 검사입니다. 잘못된 응답의 영구 대기 결함을 재현 후 수정했고, 실제 per-pixel 투명 창 및 픽셀 알파, 창 조작, 비동기 파일 응답과 본문 없는 지연 로그를 검사했습니다. 타블렛 사용자의 실제 전체 창 멈춤은 아직 재현하지 못했습니다. 상세 내용과 확인 순서는 [RELIABILITY-0.4.2.md](RELIABILITY-0.4.2.md)를 참고하세요.

## 0.4.2 정식판과 업데이트 알림
사용자 요청에 따라 0.4.2로 정식 배포합니다. 시작 시 1회 및 수동 버튼 조회만 제공하고 실행 중 주기 확인은 없습니다. 최신 정식 태그·업로드 완료 EXE·숫자 버전 비교·고정 GitHub 링크·화면 비차단·오프라인/조회 제한·언어 전환·최소 창 크기 등 31개를 더해 총 179개 검사가 통과했습니다. 공개 GitHub API 실제 접속을 확인했으며 파일 자동 다운로드·설치·실행 기능은 넣지 않았습니다. 타블렛 실기 문제 해결은 아직 확인 전입니다. [UPDATES.md](UPDATES.md).

## 0.4.3 전송문 분리·연결 비활성화
전송 중 입력이 원문 뒤에 남는 기존 동작을 재현하고 수정했습니다. 총 200개 검사(63+25+21+12+11+37+31), 설치 소유권·복원 충돌·재실행 비활성화 유지·응답 유실과 입력 복원 검사를 통과했습니다. 게임 화면의 빈 고양이 원인은 아직 확인하지 못했습니다. 실제 게임·타블렛·Windows 10 실기 검증으로 간주하지 않습니다. [RELIABILITY-0.4.3.md](RELIABILITY-0.4.3.md).

## 0.4.4 메시지 선택·복사
메시지 본문을 기존 말풍선 안의 읽기 전용 텍스트로 표시해 드래그 선택과 기본 Ctrl+C 복사를 지원합니다. 별도 복사 버튼·전용 메뉴·자동 클립보드 접근은 없습니다. 부분 선택 시 기본 복사 명령 사용 가능, 잘라내기 불가, 새 메시지 수신 중 기존 선택 유지 등을 검사했습니다. 총 204개 격리 검사(63+25+25+12+11+37+31)입니다. 모의 상태·대화 파일만 사용했으며 실제 게임 설치나 복구 설정은 변경하지 않았습니다. 클립보드 내용은 검사에서 읽거나 교체하지 않았습니다. 타블렛·빈 고양이 원인에 대한 새 해결 주장은 없습니다.
