# Bongo Cat Chat Merger

[English](README.md) · [한국어](README.ko.md) · **日本語**

**Steam Bongo Cat**の同じルームで受信した会話を、ひとつのWindowsウィンドウにまとめる軽量アプリです。C# / WPFとBepInEx接続プラグインで構成されています。他のプレイヤーはインストール不要です。

![日本語プレビュー](docs/assets/preview-ja.png)

## ダウンロードとインストール

[Releases](https://github.com/RATOY-Jeong/bongo-cat-chat-merger/releases/latest)から **BongoCatChatMerger-0.3.0.zip** をダウンロードしてください。自動生成される **Source code** は実行用パッケージではありません。Windows x64と.NET Framework 4.xが必要です。

1. ZIPを展開し、Bongo Catを完全に終了します。
2. `Install.cmd`を実行します。Steamのゲームフォルダーを自動検出できない場合は、`BongoCat.exe`を選択してください。
3. SteamライブラリからBongo Catを起動し、ルームに参加します。
4. `BongoCatChatMerger.exe`を起動し、言語を選んで開始します。

既存のMODローダーを検出するとインストールを停止します。他のローダーを上書きしないでください。`Uninstall.cmd`はインストール一覧に記載されたファイルだけを削除し、会話記録は保持します。

## 0.3.0の言語選択

- 初回起動時に **English / 한국어 / 日本語** を選択します。次回からは直接チャット画面が開きます。
- 右上のドロップダウンから、いつでも変更できます。選択は実行ファイルと同じフォルダーの`language.txt`に保存されます。ファイルがない場合や値が無効な場合は、選択画面が再表示されます。
- ボタン、接続・エラー案内、日時、会話保存の表示を切り替えます。メッセージ本文、プレイヤー名、ルーム名、ゲームから取得した絵文字名は翻訳しません。
- 言語を変えても、下書き、検索語、会話記録、送信待ちリクエスト、進行中の再接続は保持されます。自動再送は行いません。
- GitHubの案内も、上部のリンクから3言語で読めます。

## アップデート

**0.2.2～0.2.4から:** このアプリだけを終了し、新しい`BongoCatChatMerger.exe`を既存のアプリフォルダーにコピーして実行してください。以前の`BongoChat.exe`を指すショートカットも変更してください。同じフォルダーを使えばテーマ・最前面表示・絵文字表示・ゲームパスの設定を保持できます。ゲームの再起動や接続プラグインの再インストールは不要です。

**0.2.1以前から:** ゲームとアプリを終了し、旧パッケージの`Uninstall.cmd`、新パッケージの`Install.cmd`の順に実行して、新しいEXEを使ってください。会話記録は保持されます。接続に失敗した状態でSteamが起動していた場合は、一度Steamも完全に終了して再起動してください。

接続プラグインは検証済みの **0.2.2** と同じです。既存データとの互換性のため、`BongoChatBridge.dll`、インストール一覧、`BepInEx\BongoChat`の名前は維持します。

## 機能

- 下部の入力欄から送信できます。**Enter**で送信、**Shift+Enter**で改行します。IMEの変換中は確定を優先し、ゲーム本来のチャットフィルターと送信処理を使います。
- ゲーム内で発射した絵文字を元の画像で表示します。「絵文字を表示」で切り替えられます。非表示にしても記録とエクスポートには残ります。
- ダーク・ライトテーマ、最前面表示、不透明度、メッセージ・名前検索、現在のルームの最近500件のテキスト保存に対応しています。
- 「再接続」はゲームフォルダー、最近の記録、接続信号を最大12秒間再確認します。下書きと記録を保持し、不確実な送信はキャンセルして再送しません。起動中のゲームへ未ロードのプラグインを追加することはできません。必要に応じて再起動の案内に従ってください。
- ゲームがSteamを起動して再起動する際のローダー状態値の継承問題を修正しています。0.2.2ではゲームビルド **25936063** でこの起動経路を確認しました。今後の更新でも内部のチャット関数とデータ形式が維持されれば使えますが、構造変更時は修正が必要になる場合があります。

## 記録とプライバシー

インストール後に受信した会話だけを記録します。それ以前のサーバー上の会話は復元できません。記録にはルームID、Steam ID、名前、メッセージ、日時が含まれます。共有する前に内容を確認してください。

- 会話: ゲームフォルダーの`BepInEx\BongoChat\room_<ルームID>.jsonl`
- 接続状態: `BepInEx\BongoChat\state.json`
- 絵文字キャッシュ: `BepInEx\BongoChat\emotes`
- ローカル送信リクエスト・結果: `BepInEx\BongoChat\commands`

アプリは末尾の最大2MBを読み、最大500件を表示します。元の記録はディスクに残ります。アプリを閉じてもゲームが動いている間は記録を続けます。会話を別のサーバーに送信することはありません。配布ZIPには実際の会話・個人設定・ゲームの絵文字キャッシュを含めません。アバターには名前の先頭文字を使い、Steamのプロフィール画像は表示しません。

## 接続の問題と検証

接続されない場合はゲーム内でルームに参加しているか確認し、「再接続」を押してください。改善しない場合はBongo Catを終了してSteamから起動し直してください。それでも解決しなければSteamも完全に終了し、両方を再起動してください。詳細は`BepInEx\LogOutput.log`と上記の状態ファイルで確認できます。ゲーム更新により互換性の修正が必要になることがあります。

0.3.0はビルド、**言語関連25項目**、**既存機能・再接続33項目**の検査を通過し、3言語のダーク・ライト画面を確認しました。0.3.0での実際のゲーム送信について、新たなユーザー確認はまだ受けていません。[詳細な検証記録（韓国語）](docs/VALIDATION.md)。

## ソースとライセンス

`src/app`はWPFアプリ、`src/bridge`は接続プラグイン、`src/shared`は送信形式、`scripts`はビルド・インストール用、`docs`は案内・検証記録・画像です。配布ZIPの`runtime`をソースのルートにコピーし、Windows PowerShellで`./scripts/Build.ps1`を実行してください。任意の`-GamePath`でゲームを指定できます。出力先は`build/`です。コンパイルにはインストール済みゲームのアセンブリを使い、それらは再配布しません。

BepInEx 5.4.23.5、Doorstop、HarmonyX、Windows用Monoライブラリを含みます。[第三者コンポーネントの出典・ライセンス](licenses/THIRD-PARTY-NOTICES.md)をご確認ください。本アプリは非公式です。
